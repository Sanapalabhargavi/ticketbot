# 🤖 TicketBot — AI Ticket Booking Assistant

A full-stack chatbot application for booking Bus, Train, and Movie tickets.
Built for uneducated and non-tech users with multi-language support.

## 🌟 Features
- 💬 Conversational chatbot booking flow
- 🚌 Bus, 🚂 Train, 🎬 Movie ticket booking
- 🌐 Multi-language: Telugu, English, Hindi
- 👤 User login and registration
- 🎫 My Tickets page
- ✅ Booking confirmation with Ticket ID

## 🛠️ Tech Stack
- **Frontend:** React.js + Vite
- **Backend:** Node.js + Express.js
- **Language:** JavaScript
- **AI/Chatbot:** Conversational flow with session management

## 🚀 How to Run

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## 📱 How to Use
1. Register with your name and phone number
2. Select language — Telugu / English / Hindi
3. Click Bus, Train or Movie button
4. Answer the bot's questions
5. Get booking confirmation with Ticket ID!

## 🎯 Project Purpose
This project helps uneducated and non-tech users book tickets
easily through a simple conversational chatbot interface.
No complex forms — just chat and book!
